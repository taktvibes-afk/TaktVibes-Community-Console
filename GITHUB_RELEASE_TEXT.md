# TaktVibes Community Console 0.1.0 – Build 0003

Small C# learning console for Windows (.NET Framework 4.8; Visual Studio 2019).
Six built-in commands: `help`, `version`, `echo`, `time`, `cls`, `exit`.

- Standalone open-source learning project. **No private MYL kernel code.**
- Source code, MIT license, DE/EN readmes, build and verification scripts.
- The project owner verified Build 0003 startup/version and approved the release.
- Individual six-command regression testing for Build 0003 remains pending
  (all six were previously confirmed with Build 0002).
- **Source distribution only. No signed Windows EXE included.**
- Public, **self-signed** certificate included for optional local signing;
  Windows will not automatically trust it. No private signing keys included.

Download the source ZIP and, optionally, the matching `.zip.sha256` file to
verify archive integrity. Open `TVC.Console.sln` with Visual Studio 2019.
